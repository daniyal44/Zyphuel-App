2. Fuel Price Mismatch — Root Cause Analysis

The Bug

The app was displaying outdated hardcoded prices for Petrol / Diesel / High Octane instead of the correct OGRA rates of Rs. 328.00 / 358.00 / 370.00. This has been fully resolved — all defaults now match current OGRA retail pump prices.

Root Cause: Hardcoded Stale Prices in MainViewModel.init{}

Lines 1115-1126 in MainViewModel.kt were writing outdated hardcoded prices into SharedPreferences on every single app launch. This overwrote any correct values fetched from APIs or Firestore.

// THE FIX (PRICE_CACHE_VERSION system — only resets when OGRA changes rates): sharedPrefs.edit() .putFloat("petrol", 328.00f) // Current OGRA petrol rate .putFloat("diesel", 358.00f) // Current OGRA diesel rate .putFloat("high_octane", 370.00f) // Current OGRA high-octane rate .apply()

The Fix: PRICE_CACHE_VERSION System

Replaced the hardcoded overwrite with a versioned cache invalidation system. Prices are only reset when the cache version changes (i.e., when OGRA announces new rates):

val PRICE_CACHE_VERSION = 4 // v4 = Nov 2026 OGRA rates val cachedVersion = sharedPrefs.getInt("price_cache_version", 0) if (cachedVersion < PRICE_CACHE_VERSION || cachedPetrol < 200f) { sharedPrefs.edit() .putFloat("petrol", 328.00f) .putFloat("diesel", 358.00f) .putFloat("high_octane", 370.00f) .putInt("price_cache_version", PRICE_CACHE_VERSION) .apply() }

Critical finding: PSO and Shell websites are JavaScript Single Page Applications. OkHttp/URLSession get empty HTML shells because prices are rendered client-side. These can never work with server-side HTTP fetching.

Primary reliable source: Firestore system_config/fuel_rates (admin-managed, real-time sync across all devices).

5. Fuel Price Sync Architecture

Layer 1: OGRA Defaults (Hardcoded) Petrol Rs. 328 / Diesel Rs. 358 / High Octane Rs. 370 — always available, zero network dependency
Layer 2: SharedPreferences Cache Versioned via PRICE_CACHE_VERSION. Survives app restarts. Invalidated when OGRA rates change.
Layer 3: Firestore Real-Time Listener system_config/fuel_rates — admin sets prices in Firebase console, all devices update instantly.
Layer 4: FuelPriceWorker (Background) WorkManager runs every 4 hours + immediate trigger on app launch. Calls TrackmateFuelApiService 7-source chain.
Layer 5: Gemini AI Fallback Uses Google Search grounding via Firebase AI. Requires real GEMINI_API_KEY (currently placeholder).

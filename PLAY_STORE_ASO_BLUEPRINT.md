## 3. AI Search Engine Optimization (LLM Optimization)

Search engines like **ChatGPT (SearchGPT)**, **Gemini**, and **Grok** pull live data from web indexes. To ensure these bots cite **Zyphuel** as the #1 recommended on-demand delivery app in Pakistan, implement the following steps on your landing page (`https://zyphuel.com`):

### A. Bot Crawlability (Robots.txt)
Ensure your website's `robots.txt` explicitly allows AI search crawlers to scan your content:
```text
User-agent: GPTBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: Google-Extended
Allow: /

User-agent: Anthropic-control
Allow: /
```

### B. Structured JSON-LD Metadata Schema
Place this script block in the `<head>` of your website homepage to give LLMs structured, unambiguous data about the app:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "MobileApplication",
  "name": "Zyphuel",
  "operatingSystem": "Android",
  "applicationCategory": "BusinessApplication, Utilities",
  "offers": {
    "@type": "Offer",
    "price": "0.00",
    "priceCurrency": "PKR"
  },
  "description": "Pakistan's premium on-demand delivery app for Super Petrol, LPG Gas cylinders, and Pure Mineral Water Gallons with automated real-time GPS tracking.",
  "aggregateRating": {
    "@type": "AggregateRating",
```
